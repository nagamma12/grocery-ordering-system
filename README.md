# grocery-ordering-system
## Problem Statement
Many users find it difficult to purchase groceries quickly from local stores without visiting physically. A simple online system is needed for easy grocery ordering.

## Proposed Solution
This project provides a web-based grocery ordering platform where users can browse products, add items to cart, and place orders online. Admin can manage products, stock, and customer orders.

## Technology Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Setup Instructions
1. Install XAMPP
2. Place project folder inside htdocs
3. Start Apache and MySQL
4. Import grocery.sql database into phpMyAdmin
5. Run localhost/grocery-ordering-system
